Guidely Support Engineering Operating Guide

1. Incident Response & Escalation SOP:
When a P1 high-severity incident is declared, the primary support engineer must initiate an Incident Command Slack channel (#inc-yyyy-mm-dd) within 5 minutes. Update the internal status page every 15 minutes until resolution. If an incident remains unresolved after 45 minutes, escalate directly to the Engineering Director.

2. Support Engineering Onboarding Protocol:
New support engineers must complete the 5-day onboarding checklist: Day 1: System access setup & security compliance training; Day 2: Architecture overview and local environment setup; Day 3: Shadowing senior engineers on ticket queues; Day 4: Handling first assigned non-urgent tickets; Day 5: Introduction to on-call rotation schedules.

3. Document Contribution & Knowledge Base Maintenance:
To add or update internal documentation, author your changes in Markdown format and submit a Pull Request to the internal knowledge repository. All documentation updates require review and approval from at least one Team Lead prior to merging into the main branch.
